# Flappy Duck

A Flappy Bird clone featuring ducks, custom pixel art, and Progressive Web App (PWA) capabilities. Built with Vite and HTML5 Canvas.

## Features
- Choose between a Mallard, White Duck, and Rubber Duck.
- Parallax scrolling lake background.
- Responsive design for mobile and desktop.
- Installable on iOS/Android as a PWA.

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
